# Справочник команд Orion 1.0

Префиксы: `/`, `!`, `.` и текстовое обращение `Орион `. Русские псевдонимы указаны у некоторых команд. Регулярные сообщения без префикса используются только для пользовательских команд (`/command_add`). Команда `/help` работает также в личном чате.

**Цель:** обычно ответьте на сообщение пользователя либо укажите числовой Telegram ID первым аргументом. `@username` поддерживается только для ранее замеченных пользователей **этого** чата. Ни ID, ни имя пользователя не позволяют получить приватные сведения из Telegram. **Срок:** `30m`, `2h`, `1d`, `1w`, также `30мин`, `2ч`, `1д`.

**Особенности:** команда не действует на владельца, администраторов Telegram, себя или локального модератора равного/большего ранга. Инициатор может выдать только ранг строго ниже своего. Некоторые действия требуют администраторских прав **самого бота**. При отключённом `/antispam` остальные автоматические фильтры не срабатывают. Фильтр фраз — поиск подстроки, поэтому избегайте коротких многозначных слов.

**Безопасные сроки Telegram:** временные муты и баны должны быть от 1 минуты до 365 дней. Чрезмерно малые/большие сроки Telegram может воспринять как бессрочные.
