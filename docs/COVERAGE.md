# Покрытие публичных возможностей Iris

Ориентир: https://teletype.in/@iris_cm/commands. Это не продукт команды Iris и не гарантия совместимости с его протоколами, базами или тарифами.

| Публичный раздел Iris | Статус Orion 1.0 | Реализация / ограничение |
|---|---|---|
| Модерация и локальные ранги | Реализована основа | /setrank, /rank_list, /audit; Telegram owner/администраторы автоматически; без наследования прав |
| Баны и предупреждения | Реализована основа | /warn, /unwarn, /mute, /ban, /kick, /unban; не все оригинальные триггеры |
| Триггеры и автоматические наказания | Частично | Антифлуд, повторы, CAPS, ссылки, локальные фильтры, автобан после лимита |
| Доступ к командам | Частично | /access с неизменяемым минимальным уровнем опасных команд |
| Чистка чата | Частично | /purge до 100 сообщений в диапазоне |
| Настройка чата | Частично | Правила, приветствия, лимит варнов, настройки автомодерации и лог |
| Сетка чатов | Частично | Добровольные федерации и общие баны; без трансляции всех функций |
| Профили | Реализована основа | Описание, звание, статистика, репутация; нет отслеживания online |
| Статистика | Реализована основа | Сообщения, активность по дням, топ |
| Темы для модераторов | Не реализовано | Логи можно отправлять в отдельную группу |
| Голосование за команды | Не реализовано | Обычные опросы Telegram доступны |
| Глобальные Iris AntiSpam/SCAM | Не реализовано | Только локальные фильтры, антирейд и добровольные федерации |
| Ириски и VIP | Собственная игровая экономика | Ежедневные бесплатные монеты и золото, без реальных покупок |
| Развлекательные команды | Частично | Кубик и монета |
| Дуэли | Реализована упрощённая игра | Ставки в виртуальных монетах, случайный победитель, возврат по истечении |
| Кубы | Частично | Игровой кубик Telegram, без сложного рейтинга |
| Кланы | Реализована основа | Создание, вход, выход, расформирование |
| Кружки | Не реализовано отдельно | Используйте кланы как упрощённый аналог |
| Отношения | Частично | Предложения, браки и разводы; без уровней и опыта |
| Браки | Реализована основа | Двустороннее согласие, состояние и развод |
| Репутация | Реализована основа | +/-1 одному пользователю в сутки UTC |
| Награды | Реализована основа | Модераторы выдают локальные награды |
| Закладки | Реализована основа | Запись ID исходных сообщений, просмотр своих |
| Заметки | Реализована основа | Публичные заметки чата с названиями |
| Таймеры | Реализована основа | Одноразовые напоминания и повторяемые сообщения |
| Каталог чатов | Не реализовано | Нужен внешний каталог и механизм проверки |
| Биржа Iris | Частично, другая модель | Внутренняя конвертация с фиксированным курсом, без заявок |
| Inline-режим | Не реализовано | Команды работают через сообщения в чатах |
| Telegram Business | Не реализовано | Потребовалась бы отдельная настройка разрешений и сценариев |
| Репорты | Реализована основа | /report записывает ID сообщения и направляет в лог-чат |
| Розыгрыши | Реализована основа | Однократные розыгрыши с автоматически выбранным победителем |
| Интеграции Telegram | Частично | Админ-действия, опросы, кубик; нет подарков/Telegram Stars |

**Ограничения исходной версии:** одно-процессный SQLite/polling, нет внешнего веб-интерфейса, шардирования, финансового учёта реальных платежей, встроенной миграции уже существующей БД между будущими версиями. Некоторым командам нужна супергруппа. Для запуска нужен токен своего бота.

**Проверка:** `python -m pytest -q` проверяет доменную логику, транзакции и наличие маршрутов команд. Эти тесты не заменяют проверки с реальным ботом и токеном в тестовой супергруппе.
