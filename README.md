# Orion Chat 1.1 — самостоятельный аналог Iris для Telegram

Рабочий **исходный проект** русскоязычного Telegram-бота для управления сообществами и игровых взаимодействий. Это НЕ официальный Iris и не копия его сервера, базы пользователей, бренда или платной экономики. Проект предоставляется как открытый исходный код для собственного бота.

**Стек:** Python 3.10–3.14, aiogram 3.31.0, SQLite (WAL), long polling; запуск локально или через Docker Compose. Один процесс / один экземпляр бота на одну базу. Интерфейс — Telegram-команды (без веб-панели). Токен Telegram и сервер требуются от владельца; работающий бот в Telegram не создаётся автоматически.

## 1. Быстрый запуск на Windows — двойным кликом

1. Установите Python 3.10+ (рекомендуется 3.13) с https://www.python.org/downloads/ и включите **Add Python to PATH**.
2. В Telegram откройте **@BotFather**, отправьте `/newbot`, задайте имя и username и получите токен. Для Orion нужен именно **Bot Token**, а не `API_ID`/`API_HASH` с my.telegram.org.
3. Распакуйте архив и запустите **`START_ORION.cmd`** двойным кликом.

При первом запуске лаунчер автоматически:

- создаёт `.venv`;
- устанавливает зависимости из `requirements.txt`;
- создаёт `.env`;
- скрыто запрашивает токен от @BotFather и сохраняет его в `.env`;
- проверяет токен запросом `getMe`;
- проверяет соединение с Telegram;
- при сетевой ошибке пробует IPv4-only, затем **предлагает** управляемый `hosts`-fallback и HTTP/SOCKS-прокси;
- запускает `python -m orion`.

На следующих запусках готовые шаги пропускаются и бот запускается сразу после проверки соединения. Остановить бота можно `Ctrl+C`.

Для изменения токена, прокси, диагностики, повторной установки зависимостей и запуска тестов используйте **`ORION_MENU.cmd`**. Для удаления только добавленного Orion блока из Windows `hosts` есть **`REMOVE_ORION_HOSTS.cmd`**. Подробности: `docs/WINDOWS_LAUNCHER.md`.

### Сетевой fallback в Windows

Статический `hosts` не добавляется без необходимости. Если прямое соединение с Bot API не работает, лаунчер может с разрешения пользователя и UAC добавить помеченный блок:

```text
# >>> ORION TELEGRAM HOSTS >>>
149.154.167.220 my.telegram.org
149.154.167.220 api.telegram.org
# <<< ORION TELEGRAM HOSTS <<<
```

Перед изменением создаётся резервная копия `hosts` в папке `backups/`. Чужие существующие записи для этих доменов не перезаписываются. Статический IP является только fallback и со временем может перестать быть актуальным.

Если используется локальный VPN/прокси, можно сохранить, например:

```dotenv
TELEGRAM_PROXY=socks5://127.0.0.1:1080
```

или:

```dotenv
TELEGRAM_PROXY=http://127.0.0.1:7890
```

Вручную редактировать `.env` для обычной установки не требуется.

## 3. Docker Compose

При установленном Docker запишите токен в `.env`, затем выполните:

```bash
docker compose up -d --build
docker compose logs -f orion
```

Остановить: `docker compose down`. База SQLite живёт в **именованном томе** `orion_data`, который сохраняется после `down`. **Не** запускайте `docker compose down -v`, если хотите сохранить данные. Сервис не требует публикации портов и не использует webhook. Для резервной копии остановите контейнер и скопируйте том целиком.

## 4. Подключение к групповому чату

1. Добавьте **своего** нового бота в тестовую Telegram-супергруппу.
2. Назначьте его администратором, разрешив как минимум: удалять сообщения и блокировать / ограничивать участников. Для приветствий ему также нужна возможность отправлять сообщения. Для работы со старой обычной группой функции Telegram могут отличаться: рекомендуются **супергруппы**.
3. Напишите `/start` в личку боту, а затем в группе `/help` и `/settings`.
4. Вы, как **владелец Telegram-группы**, автоматически получаете ранг 5; Telegram-администраторы получают ранг 4. Можете назначать локальные ранги 0–4: ответьте на сообщение человека командой `/setrank 2`.
5. Начните с `/setrules Текст правил`, `/setwelcome Привет, {name}!`, `/antispam on`, `/antilinks on`, `/setwarnlimit 3`.
6. Для отдельного журнала добавьте бота в закрытую группу модераторов, узнайте её ID и выполните `/setlog -1001234567890`. Для проверки можно выдать тестовое предупреждение. Если журнал не назначен, записи всё равно сохраняются локально и доступны по `/audit`.

Важно: Bot API не умеет получать произвольного пользователя только по `@username`. Используйте **ответ на сообщение** или числовой Telegram ID. По имени `@username` бот сможет найти только пользователя, которого уже видел в этом чате. Ответ на сообщение — самый надёжный способ.

## 6. Безопасность и принцип действия

- Стандартные ранги: `0` участник, `1` предупреждения, `2` муты, `3` бан и настройка фильтров, `4` локальная администрация, `5` настоящий владелец группы. Это **локальные** ранги: назначение через `/setrank` не меняет Telegram-администраторов.
- Дополнительные ограничения задаются через `/access команда ранг`. Нельзя уменьшить встроенный минимальный ранг опасных команд. `-1` отключает команду. Для передачи прав самой Telegram-группы используйте настройки Telegram, а не этого бота.
- Бот защищает владельца, Telegram-администраторов, себя и пользователей с равным/большим локальным рангом от наказаний.
- Автомодерация использует подсчёт сообщений, точные локальные запрещённые фразы, обнаружение ссылок и CAPS. **Не является ИИ-модератором**, возможны ложные срабатывания. Не включайте жёсткие фильтры без тестирования.
- `/antiraid` **выключен по умолчанию**. При включении и превышении порога новых входов бот временно банит **всех новых вступающих**, в том числе законных. Включайте только после оценки риска.
- **Федерации** — добровольные группы чатов: владелец группы создаёт `/fed_create`, затем `/fed_code` (код приходит ему в личку), владелец другой группы пишет `/fed_join КОД` в своей группе. Владелец сети может применить `/fed_ban ID` ко всем чатам сети. Присоединяясь, владельцы чатов явно дают такое право; не раздавайте коды посторонним. `/fed_leave` владельца сети расформирует всю сеть. Глобальных баз самого Iris тут нет.
- Монеты и игровое золото создаются только внутри бота: их **нельзя купить за реальные деньги, вывести, обменять на рубли или Telegram Stars**. Система не использует настоящие платежи. Дуэли расходуют только виртуальные монеты.
- Для удаления своих профиля, кошелька и статистики `/forgetme CONFIRM` (с необратимыми последствиями). **Остаются** идентификаторы в истории модерации, журнале переводов, владении кланами/сетями и сообщения, физически уже отправленные в Telegram. Для более полного удаления свяжитесь с оператором своего экземпляра. Из групповой статистики удаляются ваши записи, но продолжение общения снова создаст их.
- По умолчанию сохраняются: ID участников, текущие имена и известные username, суммарное число сообщений и суточная статистика, репутация, социальные действия, игровые счета, предупреждения, жалобы и журналы модерации. Текст **всех** сообщений не сохраняется, кроме правил, фильтров, пользовательских команд, заметок, напоминаний и сообщений в жалобах (жалоба содержит только ID сообщения). Помните о местных правилах приватности и согласии участников.
- Скрипт не делает самостоятельных переводов реальных денег, не собирает пароли, Telegram-сессии или коды подтверждения. Держите `.env`, SQLite и резервные копии закрытыми.

## 7. Проверка и диагностика

На Windows сначала используйте `ORION_MENU.cmd` → **Telegram diagnostics**. Меню показывает DNS, TCP 443 и реальный `getMe`, при этом токен не печатается.

Для ручной проверки Python:

```powershell
.\.venv\Scripts\python.exe -m orion.diagnostics
```

Успешный результат содержит JSON с `"ok": true` и username бота без вывода токена.

```bash
python -m compileall -q orion
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

При первом запуске БД и таблицы создаются автоматически. Для проверки живого соединения с Telegram после запуска: `/health` в личке (если выставлен `OWNER_ID`, доступ ограничен этим ID).

Если бот не отвечает: убедитесь, что токен корректный; не запущен ли второй экземпляр с тем же токеном (polling конфликтует); не остался ли активный webhook от прежнего проекта; разрешена ли сеть до Telegram; назначен ли бот администратором. Если бот не может мутить — убедитесь, что группа является **супергруппой** и у бота есть права `Restrict members`.

**Режим использования:** учебный, личный или небольшой/средний чат. Перед промышленной эксплуатацией на десятках тысяч участников проведите нагрузочное тестирование, аудит приватности и настройте внешние бэкапы. SQLite + polling не предназначены для нескольких параллельных реплик; миграция на PostgreSQL / очереди потребует отдельной разработки.

## 8. Что не реализовано

Нет оригинальной глобальной сети пользователей Iris, его антиспам-/SCAM-баз, каталога чатов, официальных ирисок, Iris Premium, платёжных интеграций, Telegram Business, старых оригинальных достижений, полноценной торговой биржи с заявками, полноценного конструктора всех триггеров Iris, телеграм-управления рекламой, инлайн-режима и веб-админки. Вместо них реализованы свои локальные аналоги части функций. Исходный код Iris закрыт: совместимость команд не гарантируется.
